# 도전! 일반상식 퀴즈

## 프로젝트 개요

터미널에서 실행하는 4지선다 일반상식 게임입니다. 문제를 풀고 결과를 확인하거나 직접 새 문제를 등록할 수 있습니다. 프로그램을 종료하고 다시 실행해도 등록한 문제와 최고 점수가 유지됩니다.

## 주제와 선정 이유

역사, 지리, 과학, 생물, 미술을 주제로 선택했습니다. 여러 사람이 별도의 준비 없이 함께 풀 수 있고, 정답을 확인하면서 일상에서 접한 지식을 복습할 수 있기 때문입니다.

## 실행 방법

Python 3.10 이상에서 실행합니다. 별도의 패키지 설치는 필요하지 않습니다. 저장소 폴더에서 아래 명령을 입력합니다.

```bash
python3 main.py
```

## 기능 목록

| 메뉴 | 기능 |
|---|---|
| 1. 퀴즈 풀기 | 등록된 문제를 무작위 순서로 한 번씩 출제하고 정오답과 최종 점수를 표시합니다. |
| 2. 퀴즈 추가 | 질문, 보기 네 개, 정답 번호를 모두 입력하면 새 문제를 저장합니다. |
| 3. 퀴즈 목록 | 전체 개수와 질문을 등록 순서대로 보여 줍니다. |
| 4. 점수 확인 | 최고 점수와 그 기록을 세웠을 당시의 정답 수·문제 수를 보여 줍니다. |
| 5. 종료 | 저장할 변경 사항을 확인하고 프로그램을 종료합니다. |

선택한 보너스는 랜덤 출제입니다. 한 판에 사용할 목록을 복사해 섞으므로 목록 화면의 등록 순서가 유지됩니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| main.py | 프로그램 시작, 사용자 입력 중단 처리, 종료 |
| inputs.py | 숫자 범위 검사, 빈 입력과 잘못된 입력의 재입력 처리 |
| quiz.py | 개별 문제의 출력·채점과 저장 형식 변환 |
| defaults.py | 처음 실행할 때 사용하는 기본 문제 |
| game.py | 메뉴, 풀이, 등록, 목록, 최고 점수, 저장과 불러오기 |
| state.json | 문제 목록과 최고 기록을 저장하는 데이터 파일 |

## 데이터 파일

프로젝트 루트의 `state.json`을 UTF-8로 읽고 씁니다.

- `quizzes`에는 등록 순서대로 문제를 저장합니다. 각 문제의 `question`은 질문, `choices`는 보기 네 개, `answer`는 정답 번호 1~4입니다.
- `best_score`는 처음에는 `null`입니다. 한 판을 마치면 `points`(점수), `correct`(정답 수), `total`(당시 문제 수)을 기록합니다.
- 점수는 `정답 수 × 100 ÷ 문제 수`에서 소수점 이하를 버린 값입니다. 더 높은 기록을 세우면 최고 점수를 갱신합니다.
- 파일이 없으면 기본 문제로 시작하고, 내용이 손상되면 안내 후 기본 문제로 복구합니다.

복제본에서 일반상식 퀴즈의 메뉴 1~5를 확인했습니다.
